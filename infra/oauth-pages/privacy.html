Política de privacidad

Jarvis · asistente de voz personal · vigente desde septiembre de 2026

Alcance

Jarvis es una aplicación personal con un único usuario: su propio autor. No se ofrece al público, no tiene cuentas de terceros y no recolecta datos de otras personas.

Qué datos se usan

  • Google Calendar: eventos de la cuenta del usuario que autoriza, para leerlos, crearlos, modificarlos o borrarlos a pedido del propio usuario.
  • Credenciales de acceso: el token de OAuth emitido por Google, guardado con permisos restringidos en el servidor doméstico del usuario.

Dónde se guardan

Todos los datos residen en una Raspberry Pi en el domicilio del usuario. No hay servidores en la nube operados por esta aplicación ni bases de datos externas.

Con quién se comparten

Con nadie. Los datos de Google Calendar no se venden, no se ceden, no se usan para publicidad ni para entrenar modelos, y no se transfieren a terceros.

Uso de la información de Google

El uso y la transferencia de la información recibida de las APIs de Google por parte de esta aplicación se ajusta a la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de uso limitado.

Retención y borrado

La aplicación no conserva copias de los eventos del calendario más allá de lo necesario para responder a cada consulta. El usuario puede revocar el acceso en cualquier momento desde la configuración de su cuenta de Google, lo que invalida el token de inmediato.
